# 🚀 REST API - User Management (Node.js + Express)

This is a simple REST API project built using **Node.js and Express.js**.  
It allows fetching user data, displaying it in JSON and HTML format, and basic API structure for CRUD operations.

---

## 📌 Features

- 📄 Get all users (JSON & HTML)
- 🔍 Get single user by ID
- ⚡ REST API structure (GET, POST, PATCH, DELETE)
- 🌐 Dynamic HTML rendering using Express
- 🧪 API testing using Postman

---

## 🛠 Tech Stack

- Node.js
- Express.js
- JavaScript
- JSON (Mock Data)
- Postman (API Testing)
